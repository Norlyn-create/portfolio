## Run locally
This is a static website. Open `index.html` in a browser or serve the repository with any static web server.

## Deploy with Vercel
The project uses a root-level `index.html`, `styles.css`, and `script.js`. In Vercel, use the repository's root directory and the **Other** framework preset (or let Vercel detect the static site). No build command is required; the output directory is the repository root.
